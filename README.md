# MoodMusic

**Tu música, a tu ritmo.**

MoodMusic es una aplicación móvil desarrollada con Flutter que permite escuchar música, organizar canciones y crear una biblioteca personal. Su objetivo es ofrecer una experiencia sencilla y cómoda para disfrutar de la música desde un dispositivo Android.

El proyecto se desarrolló como parte de la materia **Desarrollo Móvil Integral**, aplicando conocimientos de desarrollo móvil, bases de datos, autenticación, pruebas y control de versiones con GitHub.

## Funcionalidades principales

### Usuarios

- Registro e inicio de sesión mediante correo electrónico o Google.
- Reproducción de música con controles para pausar, continuar, adelantar y cambiar canciones.
- Reproducción de audio en segundo plano.
- Biblioteca personal para agregar, editar y eliminar canciones.
- Creación y administración de playlists.
- Importación de archivos de audio desde el dispositivo.
- Extracción de audio de videos guardados en el teléfono.
- Exportación de canciones almacenadas localmente.
- Búsqueda de canciones y acceso a favoritos.
- Consulta del historial de reproducción.
- Personalización de la apariencia con modo claro, oscuro o automático.

### Administrador

El administrador cuenta con un panel desde el cual puede consultar información relacionada con el uso de la aplicación, como:

- Usuarios registrados.
- Canciones favoritas de los usuarios.
- Historial de reproducción.
- Canciones y géneros más escuchados.
- Actividad musical registrada.

## Tecnologías utilizadas

- **Flutter y Dart:** desarrollo de la aplicación móvil.
- **Firebase Authentication:** autenticación de usuarios.
- **Cloud Firestore:** almacenamiento y consulta de información.
- **Git y GitHub:** control de versiones y seguimiento del desarrollo.
- **Android:** plataforma principal de ejecución.

## Desarrollo y control de versiones

Durante el desarrollo se utilizaron distintas ramas de Git para trabajar en las funcionalidades, realizar pruebas y documentar los cambios.

Los avances se registraron mediante commits y Pull Requests, permitiendo mantener un historial de las modificaciones realizadas.

El proyecto también recibió observaciones de tres compañeros que probaron la aplicación. Sus comentarios se utilizaron para mejorar la navegación, los formularios, las playlists y otras funciones.

## Pruebas realizadas

Se realizaron pruebas para verificar el funcionamiento de los formularios, las playlists, la reproducción de audio y otras funcionalidades.

**Resultados de la versión 1.2.0:**

- 62 pruebas automáticas aprobadas.
- Análisis de código sin errores detectados.
- Compilación del APK completada correctamente.
- Pruebas de funcionamiento en un dispositivo Android.
